# Python Mini-Tools Collection

<sub>Small Python Utilities and Experiments</sub>

---

## 🇪🇸 Español

### Descripción

Colección de pequeños scripts y utilidades desarrollados en Python para experimentar con diferentes conceptos de programación.

### Herramientas

#### Fetch-Insult

Consulta un servicio externo para obtener contenido aleatorio.

Conceptos:
- Consumo de APIs.
- Peticiones HTTP.
- Gestión de respuestas alternativas.

#### Revolver Roulette

Pequeño juego experimental con lógica de turnos y representación ASCII.

Conceptos:
- Bucles.
- Lógica condicional.
- Generación aleatoria.

#### Weather API

Ejemplo de consulta de información meteorológica mediante Open-Meteo.

Conceptos:
- Peticiones HTTP.
- Procesamiento JSON.
- Integración con APIs externas.

### Estructura

| Archivo | Descripción |
|---|---|
| `fetch_insult.py` | Consulta de contenido externo |
| `revolver_roullette.py` | Juego experimental |
| `weather_api.py` | Consulta meteorológica |

### Requisitos

- Python 3.
- Conexión a Internet para las herramientas que utilizan servicios externos.
- Dependencias adicionales, si las hubiera, según cada script.

## 🇬🇧 English

### Description

A collection of small Python scripts and utilities created to experiment with different programming concepts.

### Tools

#### Fetch-Insult

Queries an external service to retrieve random content.

Concepts:
- API consumption.
- HTTP requests.
- Response fallback handling.

#### Revolver Roulette

A small experimental game featuring turn-based logic and ASCII representation.

Concepts:
- Loops.
- Conditional logic.
- Random number generation.

#### Weather API

An example of retrieving weather information through Open-Meteo.

Concepts:
- HTTP requests.
- JSON processing.
- External API integration.

### Structure

| File | Description |
|---|---|
| `fetch_insult.py` | External content retrieval |
| `revolver_roullette.py` | Experimental game |
| `weather_api.py` | Weather information retrieval |

### Requirements

- Python 3.
- Internet connection for tools using external services.
- Additional dependencies, if any, as specified by each script.
